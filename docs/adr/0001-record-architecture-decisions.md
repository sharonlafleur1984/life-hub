# 1. Record architecture decisions

Date: 2026-09-05

## Status

Accepted

## Context

The Life Hub's design decisions have lived in chat transcripts and one long
project note. Real constraints, like Google Calendar not expanding recurring
events, were discovered more than once because there was nowhere durable to
write them down.

## Decision

Decisions that shape the code are recorded here as short numbered files.

## Consequences

A decision that is not written down is not a decision. Reversing one means a
new ADR that supersedes the old, not an edit to history.
